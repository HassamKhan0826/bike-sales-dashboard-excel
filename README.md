# Bike Sales Dashboard – Excel

An Excel data analysis project focused on exploring customer characteristics and bike purchasing behavior.

## Project Overview

The project uses Microsoft Excel to clean, organize, analyze, and visualize bike sales/customer data.

The objective is to understand the characteristics of customers who purchase bikes and identify patterns that may influence purchasing decisions.

## Analysis

The workbook uses Excel analysis and visualization techniques to compare customer demographics and purchasing behavior.

The project demonstrates:

- Data cleaning and preparation
- Customer segmentation
- Pivot Tables
- Pivot Charts
- Interactive dashboard creation
- Business-oriented data analysis

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel formulas
- Data visualization

## Repository Files

- `Excel Project Dataset.xlsx` – Dataset, analysis, and Excel dashboard

## Purpose

This project was created to strengthen practical Excel skills for data and business analysis, with a focus on transforming raw customer data into an understandable and interactive dashboard.
